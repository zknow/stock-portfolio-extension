# 台股庫存

把台股持股放進瀏覽器，點工具列圖示就能看現價與報酬。單機使用，資料只存在你的瀏覽器裡。

## 功能

- 工具列圖示開啟清單，顯示每檔的現價、總報酬與今日報酬
- 報酬可切換為比率（%）或金額（NT$）
- 可隱藏成本欄位，只看現價與報酬
- 編輯頁新增、修改、刪除持股
- 權重設定頁籤：設定每檔股票與現金的目標權重
- popup 開啟「再平衡」後，依目前市值顯示每檔的現值、目標權重、現況權重、差額與買賣建議
- 點欄位標題排序
- 報價只在開啟與按重新抓取時抓取，不會背景輪詢

## 安裝

1. 下載本專案（GitHub 的 Code → Download ZIP）並解壓縮，或使用 `git clone`
2. 開啟 `chrome://extensions`（Edge 為 `edge://extensions`）
3. 開啟「開發人員模式」
4. 按「載入未封裝項目」，選擇解壓後的 `extension` 資料夾

## 基本操作

| 想做什麼 | 怎麼做 |
|---|---|
| 查看持股 | 點工具列圖示 |
| 重新抓取報價 | popup 按重新抓取（⟳） |
| 切換報酬比率或金額 | popup 的「顯示」→「單位」 |
| 隱藏或顯示成本欄 | popup 的「顯示」→「成本」 |
| 查看再平衡建議 | popup 的「顯示」→「再平衡」→「開」 |
| 設定目標權重 | 編輯頁切到「權重設定」，填股票與現金的目標權重 |
| 設定目前現金 | 權重設定頁的現金列填入金額 |
| 新增、修改、刪除持股 | popup 按鉛筆（✎）開啟編輯頁 |
| 修改股數或平均成本 | 編輯頁點該格，Enter 儲存、Esc 放棄 |
| 刪除持股 | 編輯頁按該列的刪除，確認後即刪除，無法復原 |

## 看懂畫面

- 紅色代表上漲，綠色代表下跌（台股慣例）
- 價格前的 ▲ / ▼ 也表示漲跌
- 再平衡的「差額」欄也用紅綠：正數紅色、負數綠色，代表需要增加或減少的金額
- 買賣建議只用鋼藍色，避免被讀成漲跌
- 狀態列顯示更新時間、報價來源與加權指數
- 當日無成交的股票顯示 `—` 並淡化

## 再平衡

- 股票與現金的目標權重合計必須為 100%，否則只顯示警告、不給建議
- 現值以市值計算（現價 × 股數），總資產為股票市值加目前現金
- 建議股數取整到股；現金調整量由股票交易回推，因此標示「約」
- 缺現價時整份不給建議，並列出缺少報價的代號
- 再平衡只提供試算，不會自動交易

## 資料

持股、目標權重、排序與顯示偏好、最近一次的報價都存在瀏覽器的本機儲存空間。

- 重新開啟瀏覽器或重新載入擴充功能後，資料仍在
- 移除擴充功能會一併刪除資料
- 本專案不提供匯入或匯出功能

## 限制

- 僅支援台股上市與上櫃
- 報價來源為 TWSE MIS，失敗時改用 Yahoo Finance，延遲約 20 分鐘；MIS 為非官方端點，可能因調整而失效
- 不含手續費、證交稅、股利、交易明細與已實現損益
- 報價僅供參考，投資決策與損益請自行負責
